# 开发环境总览

StackChan 基于 M5Stack CoreS3(ESP32-S3),官方支持 **四种**开发方式。本文对比各方式并给出选型建议。

---

## 1. 四种开发平台对比

| 平台 | 语言 | 难度 | 适合场景 | StackChan 专用支持 |
|------|------|------|---------|------------------|
| **UiFlow2** | Blockly 图形化 | ★☆☆ | 快速原型 / 教学 / 演示 | ✅ 有专属固件与积木 |
| **Arduino IDE** | C/C++ | ★★☆ | 产品固件开发(主推) | ✅ 有 M5StackChan 库 + 15+ 官方示例 |
| **PlatformIO** | C/C++(Arduino/ESP-IDF) | ★★☆ | 工程化 / 版本控制 / CI | ✅ board `m5stack-cores3` |
| **ESP-IDF** | C | ★★★ | 底层定制 / 性能极致 | ⚠️ 无官方专属文档,需自行驱动外设 |

另有社区 **stack-chan 开源固件**(Moddable SDK + JavaScript/TypeScript),适合想做 JS 生态应用的开发者,见 `05_stack-chan开源固件指南.md`。

---

## 2. 选型建议

- **产品固件开发 → Arduino IDE 或 PlatformIO**
  - 有 `M5StackChan` 专用库封装舵机(Motion)与顶部触摸传感器,API 简洁。
  - 其余外设(显示/扬声器/MIC/摄像头/IMU/NFC)复用 CoreS3 的 M5Unified / M5GFX 体系。
  - 团队协作 / Git 管理 → 用 PlatformIO;个人快速验证 → 用 Arduino IDE。
- **快速演示 / 非程序员 → UiFlow2**:图形化拖拽,M5Burner 一键烧录运行时。
- **JS/TS 背景 / 想用现成的可爱表情与 AI 应用框架 → stack-chan 开源固件**(Moddable)。
- **ESP-IDF**:仅在需深度定制 FreeRTOS / 极致功耗优化时考虑,需自行处理全部外设驱动。

---

## 3. 公共前置事项(所有平台通用)

### 3.1 USB 连接
- 用 **USB-C 数据线**连接电脑与 StackChan **底座口**(推荐,避免烧录时舵机误动)。
- 机身口与底座口均支持数据传输。
- macOS/Linux 一般免驱;Windows 可能需安装 CH343 等 USB 串口驱动。

### 3.2 进入下载模式(烧录固件前必做)
- **长按侧边 `RST` 复位键约 3 秒**,内部绿色指示灯亮起后松开,设备即进入下载模式。
- 烧录 Arduino / UiFlow2 / 出厂固件前均需进入此模式。

### 3.3 串口波特率
- Arduino IDE 串口监视器常用 `115200`。
- M5Burner 烧录波特率为可配置项(ESP32-S3 常用 921600 或更高)。
- 官方未给出 StackChan 默认数值,按设备实际配置。
