# 开发环境骨架使用说明

本目录提供两种可直接使用的工程骨架,均基于 Arduino 框架 + M5StackChan 库。

---

## 前置准备(两种骨架通用)

1. **USB 连接**:USB-C 数据线连接电脑与 StackChan **底座口**(推荐)。
2. **进下载模式**:长按侧边 `RST` 键约 3 秒,绿色指示灯亮起后松开。
3. **装库**:需要以下 Arduino 库(Arduino IDE 用 Library Manager;PlatformIO 见各自配置):
   - `M5Unified` ≥ 0.2.11
   - `M5GFX` ≥ 0.2.18
   - `M5StackChan` ≥ 1.0.0(封装舵机 Motion + 顶部触摸)
4. **读安全须知**:Y 轴舵机限位 5°~85°(API 50~850),X 轴无限制,切勿手动强转舵机。详见 `../01_产品规格/StackChan_产品规格书.md`。

---

## 方式一:Arduino IDE(`arduino/stackchan_quickstart/`)

适合个人快速验证。

1. 安装 M5Stack 板支持包:
   - `文件` → `首选项` → 附加开发板管理器 URLs 填:
     `https://static-cdn.m5stack.com/resource/arduino/package_m5stack_index.json`
   - `工具` → `开发板管理器` → 搜索 `M5Stack` → 安装。
2. 选板:`工具` → `开发板` → `M5Stack` → `M5CoreS3`。
3. 装库:Library Manager 搜索安装 `M5Unified`、`M5GFX`、`M5StackChan`。
4. 打开 `arduino/stackchan_quickstart/stackchan_quickstart.ino`。
5. 选端口(`工具` → `端口`)。
6. 点 `上传`。串口监视器设 `115200` 查看输出。

**示例功能**:屏幕日志 + 顶部触摸检测(单击/前滑/后滑/按下)+ 舵机 8 段动作演示(左右/抬头低头/360° 旋转/归位)。

---

## 方式二:PlatformIO(`platformio/`)

适合工程化、Git 管理、团队协作。

1. 安装 VS Code + PlatformIO IDE 扩展。
2. 用 VS Code 打开 `platformio/` 目录(含 `platformio.ini`)。
3. PlatformIO 会自动安装 `M5Unified`、`M5GFX`。
   - ⚠️ `M5StackChan` 库若 Registry 解析失败,需本地引入:将库源码放入 `lib/M5StackChan/`,或在 `platformio.ini` 加 `lib_extra_dirs = <路径>`。
4. 编译烧录:
   ```bash
   pio run -t upload        # 编译并烧录(先长按 RST 3 秒进下载模式)
   pio device monitor       # 串口监视器
   ```

**示例功能**:屏幕日志 + 顶部触摸检测 + 舵机 5 段动作演示。

## 常见问题

- **库找不到**:`M5StackChan` 公开 GitHub 仓库调研时返回 404,优先用 Arduino Library Manager 搜索安装;PlatformIO 若解析失败需本地引入。
- **烧录失败/无端口**:确认已进下载模式(长按 RST 3 秒绿灯亮);检查 USB 数据线(部分线仅供电);Windows 可能需装 CH343 驱动。
- **舵机不动/异响**:先 `Motion.goHome()` 归位,确认 `setCurrentPostionAsHome()` 已设原点;Y 轴勿超 5°~85°。
- **板管理器下载慢**:切换网络或配置代理;也可手动下载解压到 `~/Library/Arduino15/packages/m5stack/`(macOS)。

> ⚠️ 警告:Y 轴舵机限位 5°~85°,X 轴无限制;切勿手动强转舵机,否则可能造成永久性硬件损坏。
