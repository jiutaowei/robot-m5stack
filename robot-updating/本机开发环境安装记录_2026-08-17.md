## 2. 已安装的软件

### 2.1 ESP-IDF v5.5.3（编译固件必需）

- 位置：`~/esp/esp-idf`（`$HOME/esp/esp-idf`）
- 来源：GitHub 无法直连，改用 **jihulab 官方国内镜像**：
  ```bash
  git clone --depth 1 -b v5.5.3 https://jihulab.com/esp-mirror/espressif/esp-idf.git ~/esp/esp-idf
  cd ~/esp/esp-idf
  git config url."https://jihulab.com/esp-mirror/espressif/".insteadOf "https://github.com/espressif/"
  git submodule update --init --recursive --depth 1   # 23 个子模块
  ```
- 工具链安装（含 xtensa-esp-elf 14.2.0、riscv32-esp-elf、openocd 等）：
  ```bash
  cd ~/esp/esp-idf
  export PIP_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple   # pip 清华镜像（加速）
  export IDF_GITHUB_ASSETS=dl.espressif.com/github_assets         # github release 走 espressif 镜像
  ./install.sh esp32s3
  ```
- 环境激活（每次开新终端编译前）：
  ```bash
  . ~/esp/esp-idf/export.sh
  ```

### 2.2 踩过的坑（已解决）

1. **Python SSL 证书失败**：`CERTIFICATE_VERIFY_FAILED` → 运行
   `/Applications/Python 3.10/Install Certificates.command` 修复。
2. **GitHub 直连超时**：git clone / 工具链下载走 jihulab 镜像 + `IDF_GITHUB_ASSETS`。
3. **pip 下载慢**：`PIP_INDEX_URL` 指向清华镜像。
