# 米宝一号固件编译技能（必读）

> 目的：**每次编译必成功**，不再反复试错
> 适用：所有米宝一号（StackStan / ESP32-S3）固件编译场景
> 调用：在做任何编译/烧录前必读本文件，再跑 `scripts/build.sh`

---

## 0. 铁律（任何场景适用）

1. **永远用 `/Users/cobain/robot-build/fw` 镜像目录编译**，不要直接在源码目录编译。
   原因：源码目录路径含 `[ ] ( ) { } * ?` 等特殊字符，CMake `file(GLOB)` 解析失败会导致本地 component 找不到。
2. **永远用 `scripts/build.sh` 编译**，不要手敲命令。
   原因：脚本封装了 venv 激活、log 目录创建、镜像同步等所有已知坑。
3. **永远先用 `ninja -C build` 增量编译**，需要 menuconfig 才用 `idf.py`。
   原因：`idf.py` 会写 `build/log/idf_py_stdout_output_xxx` 文件，目录不存在会报 `FileNotFoundError`。

## 2. 内部原理（理解用，不要背）

### 2.1 为什么需要镜像目录？

ESP-IDF CMake 用 `file(GLOB)` 扫描 component，路径含特殊字符会失败：

```
/Users/cobain/Documents/[0]project-JHTech/...  ← 失败
/Users/cobain/robot-build/fw                   ← 成功
```

`scripts/build.sh` 自动 rsync 源码到镜像目录（含 build 排除），用户不用关心。

### 2.2 为什么必须激活 venv？

ESP-IDF v5.5 把 `esp_idf_monitor`、`esptool` 等装在专属 venv：

```
/Users/cobain/.espressif/python_env/idf5.5_py3.14_env/
```

直接用系统 python 跑 `idf.py` 会报：

```
No module named 'esp_idf_monitor'
```

`export.sh` 帮我们 source venv + 设置 PATH + IDF_PATH。

### 2.3 为什么必须创建 build/log/？

`idf.py build` 启动时把 stdout/stderr 重定向到 `build/log/idf_py_{stdout,stderr}_output_<pid>`。
目录不存在 → 编译末尾 `generate_hints()` 读 log → `FileNotFoundError`。

`scripts/build.sh` 自动 `mkdir -p build/log` 防止。

### 2.4 为什么不用 idf.py build？

- idf.py 写日志文件易失败
- idf.py 后处理耗时（生成 size 报告、提示信息等）
- `ninja -C build` 直接走 ninja 增量构建，最快

只有以下场景才用 `idf.py`：
- `idf.py menuconfig`（必须）
- `idf.py reconfigure`（CMakeLists.txt 改了强制重配）
- `idf.py -p /dev/tty.usb* flash`（烧录）

## 3. 历史踩坑（不要再踩）

| # | 错误信息 | 真正原因 | 修复 |
|---|---|---|---|
| 1 | `No module named 'esp_idf_monitor'` | 没激活 venv | `source export.sh` |
| 2 | `idf.py build` 报 `FileNotFoundError: build/log/idf_py_stderr_output_xxx` | build/log 目录不存在 | `mkdir -p build/log` |
| 3 | `ninja: error: WriteFile(.ninja_lock): Operation not permitted` | Trae 沙箱锁 | `dangerouslyDisableSandbox: true` 或本地 Terminal.app 跑 |
| 4 | `xtensa-esp32s3-elf-g++ not found` | venv 没激活 | `source export.sh` |
| 5 | `undefined reference to AppMibaoFiles::AppMibaoFiles()` | 新增 .cpp 没被 CMake 扫到 | `idf.py reconfigure`（或 `rm -rf build && full`） |
| 6 | `CMake Error: The detected IDF_PATH is not a full path` | IDF_PATH 是相对路径 | `export IDF_PATH=/Users/cobain/esp/esp-idf`（绝对路径） |

## 4. 烧录流程（编译后必跑）

```bash
# 1) 确认 USB 串口
ls /dev/tty.usb* 2>/dev/null
# 一般是 /dev/tty.usbmodem* 或 /dev/tty.usbserial-*

# 2) 烧录（替换 PORT 为实际串口）
cd /Users/cobain/robot-build/fw
source /Users/cobain/esp/esp-idf/export.sh
python /Users/cobain/esp/esp-idf/components/esptool_py/esptool/esptool.py \
    --chip esp32s3 -p /dev/tty.usbmodem* -b 460800 \
    --before default_reset --after hard_reset \
    write_flash --flash_mode dio --flash_freq 80m --flash_size 16MB \
    0x0 build/bootloader/bootloader.bin \
    0x8000 build/partition_table/partition-table.bin \
    0x20000 build/stack-chan.bin

# 或者用 idf.py 烧录（更简单）：
# idf.py -p /dev/tty.usbmodem* flash
```

**注意**：如果之前烧录过 OTA 固件，需要先 erase 后烧录：
```bash
esptool.py --chip esp32s3 -p /dev/tty.usbmodem* erase_flash
```

## 6. 调试技巧

### 6.1 编译时缺中文

错误信息：
```
[font-subset] 中文字体子集不完整，编译中止。
  missing: 密故滤虽钥附险
```

修复：
```bash
# 1) 把缺字追加到 symbols.txt
# 2) 重新生成字体
lv_font_conv --no-compress --no-prefilter --force-fast-kern-format \
  --font managed_components/78__xiaozhi-fonts/ttf/puhui-common.ttf \
  --format lvgl --lv-include lvgl.h --bpp 4 --size 16 \
  --range 0x20-0x7e \
  --symbols "$(cat main/assets/fonts/symbols.txt | tr -d '\n')" \
  --output main/assets/fonts/mibao_zh_font_16.c

# 16px 和 26px 都要生成
# 然后 ./scripts/build.sh 即可
```

### 6.2 编译时缺源文件

错误信息：
```
undefined reference to `AppXxx::AppXxx()'
```

修复：
```bash
./scripts/build.sh full
```

### 6.3 编译时找不到工具链

错误信息：
```
xtensa-esp32s3-elf-g++: not found
```

修复：
```bash
source /Users/cobain/esp/esp-idf/export.sh
echo $PATH | tr ':' '\n' | grep esp
# 必须看到 /Users/cobain/esp/esp-idf/tools
```

### 6.4 镜像目录与源码不同步

有时候用户改了源码但镜像没同步（mtime 一样）：

```bash
# 强制同步
rsync -a --delete --exclude='build/' --exclude='.git/' \
    "/Users/cobain/Documents/[0]project-JHTech/[2]硬件产品规划/[2]产品规划/[15]Stackstan/robot-updating/fw/" \
    "/Users/cobain/robot-build/fw/"
```

或者直接 `clean` 再 `inc`：
```bash
./scripts/build.sh clean
./scripts/build.sh
```
