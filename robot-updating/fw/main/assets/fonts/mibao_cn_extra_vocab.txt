# 米宝「生僻字兜底字体」字表词源（UTF-8）
#
# 用途：设备气泡用 xiaozhi 内置字体 font_puhui_common_20_4.bin（源自 puhui-common.ttf，
# 仅 6658 个码点），它缺少植保场景的高频生僻字，例如：
#   虱(U+8671) 螟(U+879F) 蚜(U+869C) 蝽(U+877D) 蛹(U+86F9) 稃(U+7A03) 蘖(U+8616) ...
# 结果屏幕上「稻飞虱」显示成「稻飞」，「稻纵卷叶螟」显示成「稻纵卷叶」。
#
# 本文件只列「词」，robot-updating/scripts/gen_extra_font.py 会：
#   1) 拆出所有汉字
#   2) 去掉 puhui-common.ttf 里已有的字（重复收录无意义，还会白占 flash）
#   3) 校验剩下的字都能在 noto-qwen.ttf 找到字形
#   4) 用 lv_font_conv 生成 assets/fonts/mibao_cn_extra_20_4.c
# 新增词条后重新运行即可重新生成字体，无需手工维护字表：
#   python robot-updating/scripts/gen_extra_font.py
#
# 注意：每行一个词或一句话，行内不要写标点以外的非汉字内容也没关系（会被忽略）。
