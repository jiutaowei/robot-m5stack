## 2. 其他 AI 的修改说明

### 2.1 错误修改（已纠正）
其他 AI 将 `main.cpp` 修改为**直接启动 xiaozhi，跳过 mooncake 界面**：
```cpp

```

**问题**：xiaozhi 退出后会执行 `esp_restart()`，导致设备重启而不是返回 mooncake 界面。这意味着：
- ❌ 无法进入会议录音
- ❌ 无法进入设置
- ❌ 无法进入物联网控制
- ❌ 无法进入个人灵感记录

### 2.2 正确方案（已恢复）
已恢复原始的 `main.cpp`，保留完整的 mooncake 界面：
```cpp
const bool skip_mooncake =
    GetHAL().getXiaozhiConfig().startAiAgentOnBoot && GetHAL().getWarmRebootTarget() < 0;

if (!skip_mooncake) {
    // 加载所有 mooncake apps（会议/设置/对话/IoT/个人记录等）
    GetMooncake().installApp(std::make_unique<AppLauncher>());
    GetMooncake().installApp(std::make_unique<AppSetup>());
    GetMooncake().installApp(std::make_unique<AppMeeting>());
    GetMooncake().installApp(std::make_unique<AppChat>());
    GetMooncake().installApp(std::make_unique<AppMibaoPersonal>());
    GetMooncake().installApp(std::make_unique<AppMibaoIot>());
    GetMooncake().installApp(std::make_unique<AppMibaoFiles>());
    
    // 等待用户点击"对话"图标
    while (1) {
        GetMooncake().update();
        if (GetHAL().isXiaozhiStartRequested()) {
            break;
        }
    }
    
    // 销毁 mooncake
    GetMooncake().uninstallAllApps();
    DestroyMooncake();
}

// 启动 xiaozhi
GetHAL().startXiaozhi();
```

**流程**：
1. 设备启动 → 进入 mooncake 界面（看到 4 个图标）
2. 用户点击"对话"图标 → 触发 `requestXiaozhiStart()`
3. 销毁 mooncake → 启动 xiaozhi
4. 用户说"退出" → xiaozhi 退出 → `esp_restart()` → 返回 mooncake

## 6. 关键技术点

### 6.1 mooncake 框架
- **作用**：米宝的主界面框架，管理多个 app
- **生命周期**：设备启动 → 加载 apps → 用户交互 → 点击"对话" → 销毁 → 启动 xiaozhi
- **退出机制**：xiaozhi 退出后执行 `esp_restart()`，重新进入 mooncake

### 6.2 xiaozhi 框架
- **作用**：AI 对话功能（ASR → LLM → TTS）
- **启动方式**：从 mooncake 触发，或开机直进（当前临时方案）
- **退出方式**：用户说"退出" → `requestXiaozhiExit()` → `esp_restart()`

### 6.3 NVS 配置
- **命名空间**：`mibao`
- **关键配置**：
  - `ota_url`：OTA 服务器地址
  - `ai_chat`：是否启用 AI 对话（默认 false）
  - `upload_url`：录音上传地址
  - `iot_url`：IoT 控制地址

## 7. 常见问题排查

### 7.1 设备没有连接 xiaozhi-server
**现象**：点击"对话"图标后，服务器日志无记录  
**排查**：
1. 检查 OTA URL 是否正确：`http://10.51.0.174:8003/xiaozhi/ota/`
2. 检查 AI Chat 开关是否打开
3. 查看服务器日志：`tail -f xiaozhi-server/server.log`

### 7.2 编译失败：Failed to resolve component 'ArduinoJson'
**原因**：路径含方括号，CMake GLOB 解析错误  
**解决**：必须用镜像目录 `/Users/cobain/robot-build/fw/` 编译

### 7.3 烧录后屏幕不亮
**原因**：bootloader offset 错误  
**解决**：确保 offset 为 `0x0`（不是 `0x1000`）
