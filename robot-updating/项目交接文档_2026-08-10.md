## 1. 项目概览

### 1.1 产品定义
- **产品名称**：米宝一号（Mibao One）
- **设备 ID**：`mibao-01`
- **硬件平台**：M5Stack CoreS3（ESP32-S3，320×240 IPS LCD，AXP2101，SD卡）
- **基础框架**：xiaozhi-esp32 v1.4.3 + mooncake 双框架
- **核心功能**：
  1. 农业领域 AI 对话（阿里云百炼 qwen-plus）
  2. 会议录音（本地存档 + Web 管理）
  3. 个人灵感记录
  4. 物联网控制（对接硅基一号温室系统）

### 1.2 技术栈
```
设备端：ESP32-S3 + LVGL 9.4 + FreeRTOS + xiaozhi-esp32 + mooncake
AI：阿里云百炼（ASR=paraformer-realtime-v2 / LLM=qwen-plus / TTS=cosyvoice-v2）
后端：FastAPI + Python 3.14 + sqlite（MacBook 本地）
物联网：HTTP POST 到树莓派 Flask（10.51.1.205:5000）
```

## 4. 当前问题详细分析

### 4.1 问题现象
1. 设备成功连接 WiFi（屏幕显示 WiFi 图标）
2. 设备设置中 OTA URL 已配置为 `http://10.51.0.174:8003/xiaozhi/ota/`
3. 设备设置中 AI Chat 开关已打开
4. **但点击"对话"图标后，屏幕先显示"AI 对话即将接入"，然后进入黑色背景 + 眼睛界面（StackChan AI）**
5. **服务器日志没有任何设备连接记录**

### 4.2 问题根因
从代码分析：
```cpp
// app_chat.cpp:110
if (mibao::isAiChatEnabled()) {
    GetHAL().requestXiaozhiStart();
} else {
    mclog::tagInfo(getAppInfo().name, "ai_chat disabled, show placeholder");
}
```

设备显示占位页，说明 `mibao::isAiChatEnabled()` 返回 `false`。

**根本原因**：设备端 NVS 配置未正确保存。虽然用户在界面上打开了开关并点击了"Save"，但配置没有写入 NVS 或重启后丢失。

### 4.3 临时解决方案（已实施）
修改 `app_chat.cpp`，无条件启动 xiaozhi：
```cpp
// 临时修改：无条件启动 xiaozhi，绕过配置保存问题
if (mibao::isAiChatEnabled() || true) {  // 临时：无条件启动
    mclog::tagInfo(getAppInfo().name, "ai_chat enabled (or forced), request xiaozhi start");
    GetHAL().requestXiaozhiStart();
} else {
    mclog::tagInfo(getAppInfo().name, "ai_chat disabled, show placeholder");
}
```

## 9. 已踩过的坑（避免重犯）

### 9.1 编译相关
- **路径方括号** → CMake GLOB 把 `[0]` 当字符类 → 必须用镜像目录 `/Users/cobain/robot-build/fw/`
- **ArduinoJson 找不到** → v5.5.3 不扫描本地 `components/` → CMakeLists.txt 加 `EXTRA_COMPONENT_DIRS`
- **Python 版本** → xiaozhi-server 必须用 Python 3.10（依赖锁了 torch==2.2.2）

### 9.2 烧录相关
- **bootloader offset** → v5.5+ 必须 0x0，不是 0x1000
- **erase_flash** → 每次烧录新版本前先擦除

### 9.3 硬件相关
- **屏保尺寸** → 不要用 220×220，会被 240×240 屏裁 → 统一 ≤150×150
- **录音架构** → 必须 FreeRTOS task 主动轮询 codec，不能用被动回调 `onMicData`

## 10. 警告与注意事项

### 10.1 编译/烧录
- ❌ 不要在 Trae 内置终端跑 build/usb 操作（沙盒限制）
- ❌ 不要用含方括号的路径直接 build
- ❌ 不要用 Python 3.14 跑 xiaozhi-server（必须用 3.10）
- ✅ 编译/烧录必须在 macOS Terminal.app 中执行
- ✅ 烧录前必须 `erase_flash`

### 10.2 代码规范
- ✅ 日志用 `mclog::tagInfo`，不用 `ESP_LOGI`
- ✅ 字体 fallback 严禁 `const_cast` 修改
- ✅ LVGL 回调禁止做 HTTP/cJSON 等深栈操作
- ✅ SD 访问包在 `SdCardAccessGuard` 内
- ✅ 录音必须 FreeRTOS task 主动轮询 codec

### 10.3 安全
- ❌ API Key 严禁入库/入 git/出现在日志或报告中
- ✅ 对外展示一律用 `sk-***` 掩码
