AI 对话 · 链路层

AI xiaozhi-esp32 · 阿里云百炼 · WebSocket 双工
🎙️

语音识别 ASR

设备采集 16kHz 单声道 PCM 音频，通过 WebSocket 实时流式上传。服务端使用阿里云百炼 Paraformer 模型进行语音转文字。

paraformer-realtime-v2
🧠

大语言模型 LLM

收到转写文本后，以"金禾天成农业专家"人设调用 LLM。返回自然语言回复，支持工具调用（MCP）控制设备。

qwen-plus（百炼）
🔊

语音合成 TTS

LLM 返回文本后，使用 CosyVoice 模型合成语音。服务端将 PCM 转为 Opus 编码，通过 WebSocket 推回设备播放。

cosyvoice-v2 / longcheng_v2
数据流向：
🎤 设备麦克风 → Opus 编码 → WebSocket → xiaozhi-server → ASR → LLM(MCP工具) → TTS → Opus → WebSocket → 📢 设备扬声器
系统提示词：农业专家，精通作物栽培/水肥/植保/温室环控，回答口语化便于语音播报

📼 录音管理

方法路径说明
POST/api/recording/upload设备上传 WAV 文件
GET/api/recording/list?type=&page=&page_size=分页列表（meeting/personal）
GET/api/recording/{id}下载录音文件
DELETE/api/recording/{id}删除录音（文件+记录）
POST/api/recording/{id}/transcribe异步转写（百炼 ASR）
POST/api/recording/{id}/summarize纪要总结（百炼 LLM）
GET/api/recording/{id}/transcript查看转写结果+总结

🏭 物联网代理

方法路径说明
GET/api/iot/devices执行器清单（4个默认设备）
POST/api/iot/control转发控制指令到树莓派 Flask
转发目标
树莓派地址http://10.51.1.205:5000
执行器fan / pump / light / heat
控制方式POST actuator_control

📟 设备配置管理

方法路径说明
GET/api/device/config设备开机自动拉取
GET/api/admin/device管理页读取配置
POST/api/admin/device管理页保存配置
返回字段（JSON）
